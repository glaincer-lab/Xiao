# 小二（Xiao）设置系统与 UI 设计规划

> 本文件是「设置系统 + 界面」的设计记录与后续实施依据。当前方案默认维持现状（方案②），但所有可选项都要在「设置」里可切换，供最终用户和未来的自己选择。

## 一、语音方案（顶层方案选择器）

| 方案 | 唤醒 | 转录 ASR | 大模型 LLM | 播报 TTS | 唤醒词 |
|---|---|---|---|---|---|
| ① 全云 | 本地 VAD + 云转写匹配 | 云 | 云 | 云 | 可改 |
| ② 轻本地（当前） | sherpa 固定「小二」 | 云 | 云 | edge | 只能调灵敏度 |
| ③ 本地强 | VAD + 本地识别 | 本地 | 本地/云 | edge/piper | 可改（转写方案） |

关键事实：
- 「云唤醒」没有专门服务 = VAD 收音 + 云端实时转写 + 关键词匹配。
- **MiniCPM-o 只「听/理解」，不会「说」（TTS）**，TTS 需另配 edge/piper。
- 本地识别引擎：funasr/SenseVoice（轻，CPU 能跑）→ 先做；MiniCPM-o（重，需 GPU，效果好）→ 以后再上。

## 二、每个环节的可选项

1. **唤醒**：引擎（sherpa 固定词 / VAD+转写匹配）；唤醒词（仅转写方案可编辑）；灵敏度（低/中/高三档，映射阈值）；播报中可打断开关。
2. **转录 ASR**：云（阿里云 fun-asr 当前 / Azure…）→ 弹 API Key+AppKey；本地（funasr/SenseVoice / MiniCPM-o）→ 附硬件需求标签。
3. **大模型 LLM（两处分开）**：
   - 聊天/普通任务：云 deepseek（当前）/ 千问 / 其它 OpenAI 兼容 → Key+base_url+model；本地 ollama。
   - DSH 内部模型：单独一栏（改 headless profile）。
   - temperature 等参数。
4. **播报 TTS**：edge（当前，免费无 Key）→ 音色列表+▶试听+语速；付费云（阿里云/火山/Azure/OpenAI）→ 弹 Key+音色+试听；本地 piper。
5. **执行路由**：auto/chat/dsh；dsh 关键词列表；DSH 命令/工作目录/超时；DSH 环境变量（键值对，如 HTTP_PROXY）。
6. **权限审批**：五类常驻授权开关；允许/拒绝口头词、超时；权限关键词规则；**一次性 vs 永久授权**（「这次允许」=一次性放行，「以后都允许」=写入常驻授权）。
7. **话术与行为**：退下/清空历史/关机 的开关与话术；任务进展/取消短语。

## 三、遗漏的关键配置（已确认补入）

1. **音频设备**：输入设备（麦克风）下拉、输出设备（扬声器）下拉、「麦克风回声测试」按钮（录一段立即回放）。
   - 注：麦克风枚举大概率现成；扬声器需把 TTS 播放从 pygame 换成 sounddevice/pyaudio 才能按设备选（一处小重构，需先确认现有 mic.py/TTS 用的库）。
2. **对话记忆/上下文**：记忆轮数、上下文窗口(K)、「一键清空当前对话」按钮。（仅对聊天 agent 生效；DSH 任务仍单轮无记忆。）
3. **System Prompt（人设）**：多行 Textarea + 内置模板（严谨管家/幽默闲聊/专业助理…）。
4. **健康检查 + 自动降级**：各 API 连通性状态灯；「云挂了自动切本地 Ollama」开关（fallback，进阶后置）。
5. **DSH 环境变量**：键值对列表。

## 四、设置界面交互（参考 UI_reference）

- **快速抽屉**：右上角「⚙」滑出，5 个高频项（方案预设 / 唤醒灵敏度 / TTS 音色 / 语速 / 人设）。

- **全程深色商务风**（不用参考的浅色模板）。

## 五、字段注册表架构（核心）

字段元属性：`path / label / type / options / group / show_if / validator / apply(热|冷) / secret / default / help`。
- `show_if`：条件显示（如唤醒词框仅 `wake.engine == vad_asr` 时显示）。
- `validator`：校验（Key 格式、音色文件存在）。
- `group`：分组折叠（音频硬件 / 云凭证）。
- 后端 `GET /api/settings/schema` + `GET/POST /api/settings`（校验+保存+应用）。
- 前端按 schema 自动渲染，替换写死的 TABS。
- 「恢复默认」用注册表默认值。

样例：
```python
Field(path="wake_word.keyword", label="唤醒词", type="text",
      group="唤醒", show_if={"wake.engine":"vad_asr"}, apply="hot")
Field(path="tts.cloud.api_key", label="API Key", type="secret",
      group="播报 TTS", show_if={"tts.provider":"cloud_paid"})
```

## 六、UI 对比结论（本次）

- **星云重做（最高优先）**：当前 Three.js 单色(青蓝) 2600 粒子 + AdditiveBlending 高亮 → 糊、霓虹、AI 模板；状态切换整片变绿/粉/橙很跳。改为参考 `UI_reference/src/NebulaCanvas.tsx` 的 Canvas 2D 方案：300 粒子、柔和多色调色板（紫/靛/青/蓝紫/青绿，muted 不霓虹）、轨道+椭圆+湍流+呼吸+拖尾+柔光晕，深空底。颜色按商务蓝基调再压一档饱和度。
- 气泡已改微信风（无头像、实心蓝/灰蓝、尾巴角）；参考的「名字+时间戳小标签」可选加。
- 可加「STANDBY / PROCESSING」浮标签细节（等宽小字，克制）。

## 七、实施顺序（后续由 agent 规划）

1. 后端：字段注册表 + `/api/settings/schema` + `/api/settings`（校验/保存）+ 音频设备枚举 + 健康检查接口。
2. 前端：设置页改「注册表自动渲染 + 快速抽屉 + 高级页」；星云重做成 Canvas 2D 柔和版。
3. 分期：A 骨架（多数冷生效、界面诚实标注）→ B 便宜参数改热生效 → C 重参数保存后自动重载模块。
