## 1. 目的与范围

交付**可复用的"观察会话框架"**+首个场景（穿搭建议）；后续场景（伤口/快递单/桌面物品）是配置不是新开发。

**明确不做**：持续视频流上传（Gemini Live 式常开——贵且违反"默认关"红线）；原始帧落盘；医疗诊断（字段=观察记录非诊断，呈现保持"我不是医生"话术）。

## 2. 前置依赖

- 现有底座：多模态贴图管线（`ChatMessage.images` + OpenAI vision parts 转换）、麦克风/VAD、星云渲染、路由层意图识别
- 视觉方案：云默认 qwen-vl-max（复用 DashScope key）｜备选 glm-4v/gpt-4o｜本地可选 MiniCPM-o——**第五环节进多方案卡片管理**
- 新增硬件面：摄像头访问（getUserMedia，经 M0 授权中心）

## 3. 数据结构

```yaml
look_session:
  id, scene: outfit|wound|custom
  state: S0-S6
  segments: [ {start_ts, frames: [jpeg_buffer], summary_text} ]   # 帧内存驻留，会话结束焚毁
  vlm_calls: [ {段id, json返回} ]
  keyframes: []              # ≤3 帧代表性帧（信息熵最高）
  text_conclusions: []       # 唯一持久化产物（入 M1 记忆）
compliance:
  local_only_keywords: true            # 黑词命中→本机沙盒
  entity_map: {"我妈": "User_Kinship_Mother", "张总": "User_Leader_Alpha"}
  dynamic_cache: {"王五": "User_Relation_B"}   # 后置入册的动态新增
```

**场景结构化模板（分场景配置）**：
- 穿搭：`{单品列表, 主色调, 层数}`
- 伤口：`{红肿程度1-5, 边缘是否清晰, 面积估测}`——**医疗边界：字段=观察记录非诊断**

## 4. 状态机 / 流程（S0-S6 定稿）

```
S0 需求识别（意图词表+LLM兜底；摄像头未开；小二复述预告）
S1 同意开启（首次问"打开摄像头可以吗"→同意记忆化可撤回）
S2 开窗就位（本地预览窗纯本地零出网；语音"好了"+按钮双通道确认；30s提醒/60s礼貌退出）
S3 观察互动（分段采帧 3段×5-8s×1fps×480p → 段末轻量VLM即时评论+指令"转个身"→循环；
   每段只传本段帧，文字总结下段携带不重传；随时"行了"跳S4；VLM失败重试一次再降级）
S4 结束采集（先停帧→再关窗→后说话；帧内存即焚，磁盘零落盘）
S5 建议生成（文字链综合为主不再调VLM；可带≤3关键帧二次VLM；缺场合先反问再定稿）
S6 反馈闭环（接受/不接受/部分→三态全写入M1记忆；拒绝可追问一次原因，不答不追问）
```

**规则写死**：
- 帧生命周期=整个 S0-S6，会话结束统一焚毁（S5 在会话内可复核——消解"帧即焚 vs 多段复核"矛盾）
- 关键帧选取=第一程 VLM 描述信息熵最高的 3 帧（非时间均匀）
- 结构化字段按场景模板；无结构化字段按模板重试一次，仍失败 S5 降级"信息不足，建议重拍"
- **视线对齐**：S3 中星云随 VLM 结构化返回的"位置"字段偏移/高亮——用户看到"它在看那里"
- 成本封顶：单会话硬上限 3 段×8s×1fps=24 帧
- **S5 二次 VLM 出网规约（v4.1.1）**：S5 关键帧/文本出网前**同样过 M0.2 网关**（占位混淆）；黑词命中则该次二次 VLM 按"仅用文字链综合"降级，不因图像内容出网而绕过网关
- 升轨：模糊请求先呈现轨回应+主动补"要我翻原始记录吗"一键升任务态

## 5. 规则与话术

- S5 建议结构：总评一句人话+分项（配色/层次/场合匹配）+一条可执行建议；低置信走降级话术（"第一印象是……但我不太确定，你有看到什么特别的地方吗？"）
- S6 反馈三态全部入记忆（负反馈更有画像价值）；拒绝仅追问一次原因
- 横向复用：穿搭/伤口/快递单/桌面物品=同一框架不同配置（模板+段策略+建议模板）

## 7. 验收断言

- EVAL.md：场景一（两轮时序：首发明文出网豁免→回收入册→次轮混淆生效）
- 模块级：会话结束帧零残留断言（内存扫描）；单会话帧数 ≤24 硬上限断言；S2 就位前零出网断言；还原校验日志断言；黑词命中会话出网调用=0

## 8. 开放问题

1. 摄像头并发冲突（用户同时开视频会议）→ 会话启动前检测设备占用，人话报错（"摄像头正被 XX 使用"）。
2. 预览窗尺寸/位置记忆（用户偏好）未设计。
3. 低置信降级话术的阈值（VLM 返回分数）需实测标定。
