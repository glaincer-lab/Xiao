## 1. 目的与范围

"陪你长大"——双向成长记录、微小请求（真实互惠）、记忆全量导出/迁移、纪念锚点。这是"家人"叙事的落点，也是**业界双空白**（双向成长+人物卡关联呈现）。

**明确不做**：假成长（里程碑必须对应真实能力事件，与版本/插件体系挂钩）；奖杯式推送（无弹窗无解锁通知）；表演疲惫博关心（人格宪法红线 2）。

## 2. 前置依赖

- M1：记忆条目与人物卡（成长事件的素材源与持久层）
- M2：同乐态（见证呈现）、元对话态（关联叙事）
- M3：心跳通道（回顾推送走此通道，克制）
- 现有底座：`logs/` 数据资产、`memory/list` API

## 4. 状态机 / 流程

### 4.1 双源入册制（写死）

```
系统识别候选（schema：任务完成 + S6 反馈正向 = "办成一次事"）
  → 不弹通知；下次用户闲聊时朋友态轻提一次："刚才那事成了，要记进咱们的本子里吗？"
  → "好/记上" → 入册（canon=true）
  → "不用" → 丢弃 + 同类事件 3 个月冷却
册封询问：周 ≤1 次（分项上限），且**受全局周询问预算 ≤5 次/周约束**（见 `EVENT_REGISTRY.md` §5，与 M1 澄清/M2 印证共享，优先级最低，冲突时顺延下周）。**Aging Policy（v4.1.1 终审）**：若某成长记录候选因全局预算挤占连续 **3 周被顺延**，第 4 周该特定条目优先级**无条件提权至与 M1 澄清同级**，强制消耗配额输出——防低优先级功能在高压期饥饿死锁（成长叙事空窗）。
呈现：双轨分栏并列、时间倒序、无奖杯弹窗；用户翻看时才渲染
```

### 4.2 微小请求（三类，月级，可跳过）

1. **求反馈**："你那句'干得漂亮'我能存进成长记录吗？"
2. **求确认偏好**：低置信条目的顺带确认（走 M1 配额时挂此名义）
3. **求人类经验（数字无能式提问）**："我在语料里看到'微醺'，我懂字面意思，但能告诉我你第一次体验到它是什么感觉吗？我想写进世界观卡片。"——承认没有人类体验并请教，**不表演感受**（宪法零冲突）

### 4.3 记忆全量导出/迁移

一键打包（记忆/画像/人设/人物卡/成长记录）→ 新设备导入 → **搬家不失忆**。选择性删除（"忘掉那段"被遗忘权）。导出包含高密度隐私 → 提示加密。

### 4.4 纪念锚点与哀伤陪伴（与 M1.6 联动）

丧失关系建只读记忆 → 见证式询问（"想聊聊这段往事吗？"）月度+可关闭；3/7/30 天节奏由 M3 哀伤调度驱动。

## 5. 规则与话术

- **叙事宪章**：一切自我表达=数据事实的浪漫化表达；共同回忆用"咱们"
- 回顾推送走 M3 心跳通道受预算与总闸门约束；被动问（"我最近怎么样"）随时可答不受限
- 小二轨诚实性：capability_event 必须可追溯到真实系统能力事件，不可编造
- RETURNING 简报复用（M0.1）：三源素材+数字事实浪漫化模板

## 6. 模块间接口（事件总线契约表）

## 7. 验收断言

- 模块级：入册必须经用户册封断言（无 canon=true 的系统自入册=0）；同类冷却 3 个月断言；导出包含四类资产完整性断言；微请求月频断言；双重轨呈现分离断言（不混合渲染）
- EVAL 关联：DORMANT/RETURNING 场景（简报三源）；成长记录只读锚点的"见证询问月度+可关闭"断言

## 8. 开放问题

1. "办成一次事"的判定 schema 首版较窄（任务完成+S6 正向），非任务型成就（生活里程碑）靠用户口述入册——覆盖率待观察。
2. 导出格式标准化（JSON）与跨版本兼容策略未定。
3. 共同记忆的"咱们"叙事自动生成质量未验证（首版模板化）。
