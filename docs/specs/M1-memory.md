## 1. 目的与范围

让小二"记得住、容得下变化、从不拿记忆跟你对质"：分层记忆+冲突协议+听错入口分级+人设世界观+亲友人物卡+哀伤标签+惯例画像。

**明确不做**：不做向量库（首版负资产）；不做自动心理画像（人格宪法）；呈现轨滤镜的 180 天逻辑 MVP 延后（记忆库存不满 180 天天然不触发，schema 与架构位先行）。

## 2. 前置依赖

- M0.2 出网网关（已实现，巩固摘要出云必经）｜M0 宏观状态机（IDLE 触发增量巩固）｜**跨模块事件总线 `backend/event_bus.py`（已实现，M0 §3.0，全系统唯一通信信道）**——M1 发布/订阅一律走 `bus.on/emit`，事件名见 `EVENT_REGISTRY.md`
- 现有底座：`memory.py` 单例+`logs/memory.json`（FIFO 100）+`GET /api/memory/list`（只读清单→本版扩展编辑/删除）
- 外部：巩固摘要走云 LLM API（经网关）；memobase（Apache-2.0）仅作画像组织方式参考

## 3. 数据结构（五要素 schema，第一天定稿）

```jsonc
{
  "id": "mem_xxx",
  "content": "不喝咖啡",                       // 内容
  "scope": "global|period|occasion|event|place",  // 作用域五分
  "scope_detail": {"until": "2026-09-15"},     // 作用域参数（时段终点等）
  "effective_at": "2026-08-30",                // 生效时间
  "source": "explicit|behavior|inferred",      // 来源
  "status": "active|locally_overridden|expired|pending_clarify",  // 状态
  "confirmed": false,                          // 听错分级：高风险复述确认后 true
  "affective_luminance": 0-5,                  // 情感高光度（巩固层）
  "confidence": 0-1                            // 置信度（推断型随时间降权）
}
```

**存储分层**：
- **数据轨（100% 物理保留，写死）**：`session_logs`（会话原文）/ `raw_frames_meta`（帧元数据与文字结论；帧图像即焚）/ `context_snapshots`。仅供 M6.3 导出 / 安全审计 / M1.1 仲裁。严禁自动化脚本洗数据
- **呈现轨（情感健忘）**：巩固摘要+情感标签。>180 天记忆在 Context 注入层硬截断原始细节（LLM 看不到，架构级保证）
- **任务态例外（v4.1.1 沙盒面板，替代直通）**：判定=动词+上下文双信号（`action_verbs_task`/`action_verbs_recall` 词表进 config）；**安全默认：不确定→任务态放行**（误判放行代价 < 误判拦截代价）；模糊请求先呈现轨回应+"要我翻出原始记录吗"一键升轨。**升轨只读面板（v4.1.1 关键）**：捞出的原始明文经**显式沙盒隔离面板**渲染——只作只读文本框（Three.js 侧边栏/独立组件）挂出，**严禁将原始明文重新喂回当前对话 LLM**（否则未脱敏高危黑词穿透情感滤镜与社会处理，人设破功）。原则：**小二用嘴保持健忘，屏幕负责诚实**。**MVP 降级契约（v4.1.1 终审）**：冲刺内若 UI 侧边栏来不及做，允许降级为**只读 Markdown Code Block**（``` 包裹纯文本）在当前会话流挂出；但必须经代码审计确保该文本节点**不对 LLM 开放检索接口（Context Retrieval Window）**——降级的是渲染形式，不是隔离原则。

**容量策略**：会话日志全存；巩固摘要按月归档；画像条目上限 500（超限低置信淘汰）。
**加密预留（v4.1.1）**：schema 预留 `encrypted` + `enc_token` 字段（首版不启用，DPAPI 本机绑定为候选）；避免 MVP 后积累敏感记忆再迁移方案的高昂成本。

## 4. 状态机 / 流程

### 4.1 沉淀管线

```
对话/事件 → 候选抽取(云LLM,经M0.2网关,suggested_entities顺风车NER) 
  → 与既有记忆冲突检测 → 无冲突:写入对应层
  → 冲突:新条目入"待澄清"态（两说并存，不覆盖）→ 攒入周配额澄清队列
用户行为事件（M0 偏好引擎转交）→ 同上（source=behavior）
```

### 4.2 冲突三协议（写死）

| 场景 | 协议 |
|---|---|
| 沉淀时冲突 | 高价值偏好顺口澄清一次（二选一问法："下次推荐辣的还是不辣的？"）；低价值不问，按 scope=period 保守存 |
| 使用时冲突 | 直接服务绝不指责；行为连续 3 次违背同一记忆 → 温和确认一次（"最近又喝回咖啡啦？把之前那条划掉？"） |
| 身份级变化 | 记事件 + 一次批量迁移确认（"搬到上海了？默认城市改了，常去的店还留着吗"），不纠缠 |

**检索合并规则**：局部>全局，新>旧，**行为>声明**；待澄清条目两说并存，检索默认返回**声明**+末尾模糊提示（消耗周配额）。

**配额体系（写死，v4.1.1 受全局预算约束）**：记忆类澄清+周期体检合计 **每周 2-3 次封顶**（此为分项上限）；**且整体受全局周询问预算 ≤5 次/周约束**（见 `EVENT_REGISTRY.md` §5，与 M2 印证/M6 册封共享，按优先级竞争）。优先级：冲突澄清 > 周期体检（满则顺延）。

### 4.3 听错入口分级（关口前移）

| 风险 | 场景 | 动作 |
|---|---|---|
| 高 | 记忆写入/数字日期人名/不可逆指令 | 即时复述确认（"四月十二，对吧？"）→ 确认才入库+打 confirmed 标 |
| 中 | 可逆任务 | 直接执行（执行结果即反馈） |
| 低 | 闲聊 | 不反馈 |

检测信号：时长字数比异常/VAD 切碎/语义残句/数字日期人名高危词（ASR 置信度字段待核实官方文档前不依赖）。反馈形态：复述确认/反问补充/无声重听（星云"没听清"形态，不开口）。音频零留存。

### 4.4 巩固调度（三源规则）

触发：锁屏 或 无键鼠 >15 分钟（GetLastInputInfo 二元判断）。**优雅退避（v4.1.1，替代"立即中断强杀"）**：用户回来时宏观状态立即切回 ACTIVE（对用户无感），但后台网络线程打 `cancelled` 标记——**任其静默跑完网络 I/O 并丢弃返回值，严禁在网络 I/O 中途强杀进程**（云 API 2-5s 延迟里强中断会致回调悬空/状态机锁死）；已完成段保留，未完成段下窗口续做。**写锁排他性（v4.1.1 终审）**：cancelled 旧线程返回后**绝不允许执行任何持久化写锁与内存缓存覆盖**（防旧画像残留覆盖用户刚说的"记住X"）；新发生的日常交互写入拥有**绝对排他写权限**。引擎：云 LLM 经网关（CPU≈0）。夜间不批处理（睡眠规避，唤醒后补）。**原子提交（v4.1.1）**：巩固分"提取候选→提交画像"两步，提交画像为原子操作（全部写入或回滚到上一版本）；失败保留旧版+记 `consolidation_pending` 标签，下次巩固优先续做而非从头。

## 5. 规则与话术

- **四原则**：好奇不质询、先服务后学习、确认带选项、永不翻旧账
- 澄清问法只许二选一；"你要忘掉那条X"→ 立即删并复述确认
- 记忆呈现话术：>180 天细节追问 → 骨架三件套（承认记不清∨模糊）+情感补位+无黑话；参考："具体名字我真不记得了，我那时候只顾着记你的高兴了……"

## 6. 模块间接口（事件总线契约表）

| 事件名 | payload | 发布者 | 订阅者 | 备注 |
|---|---|---|---|---|
| `memory.profile_updated` | `{版本,变更字段}` | M1 | M2 | 姿态缓存刷新（快照式） |
| `memory.clarify_request` | `{条目id,二选一项}` | M1 | 会话层 | 消耗周配额 |
| `posture.changed` | `{前态,后态}` | M2 | M1 | 巩固提取策略按姿态调整（订阅事件，非回调） |
| `user.feedback` | `{目标,三态,原因}` | M0 偏好引擎 | M1 | 转为 behavior 条目 |
| `tool.remember` / `tool.forget` | `{条目}` | 会话层 | M1 | 显式记忆 API（保留现有） |

**禁止**：M2/M3 直接调用 M1 内部函数——一切经总线事件+只读快照。

## 8. 开放问题

1. 动词双清单首版权重与词条集需实测调优（灰度期采集）。
2. 敏感话题分级存储（健康/情感类标记后加密存）的加密方案未定（候选：DPAPI 本机绑定）。
3. 检索注入的相关性算法首版用关键词+时间衰减加权，向量检索是否引入待记忆量 >1000 条后再议。
4. **任务态放行的长期替代（v4.1.1）**：MVP 依赖"不确定默认放行"成立；长期需将动词分类准确率提升至 ≥90%（词表→分类模型）作为放行替代——放行误判的隐私代价靠准确率收敛，永久放行不可取。
