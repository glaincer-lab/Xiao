## 一、北极星

**生活在你电脑中的助手、朋友、伙伴**——全能型陪护人：

- **情感陪伴**：帮你干活，记录你的成长和它自己的成长；开心同乐，低落解闷
- **语音交互**：桌面常驻语音对话，未来扩展外接语音设备
- **智能控制**：控制电脑程序、控制家里设备、规划行程、饮食穿着建议、传感器感知后提前行动

## 二、三条产品哲学

1. **小二的记忆要像伙伴的记性**：记得住、容得下变化、从不拿记忆跟你对质；温度给呈现，审计留原始
2. **主动但克制**：没有记忆的主动是骚扰，有记忆的主动才是伙伴；一切主动源收口到一个总闸门
3. **感知先于行动，行动必有验证**：物理世界的每个动作先查状态、后执行、再读回确认

## 三、关系维护十维度

起居照看 / 情绪感知回应 / 大事参与 / **亲友网络维护**（人物卡）/ 见证与肯定 / 边界与放手 / 小二自己的存在（含真实互惠）/ 共同记忆（数据事实的浪漫化表达）/ 矛盾与修复（三段式拒绝+建设性冲突）/ 长期承诺（搬家不失忆）

（行为设计映射与支撑里程碑详见 ROADMAP §1.4）

## 四、沟通姿态系统（八态）

管家 / 朋友 / 陪伴 / 顾问 / 医护 / 应急 / 同乐 / **元对话**（重武器，月级）

首版规则引擎判定卡（信号×权重×退出×误判退路），不做 ML；不确定默认朋友态；语音覆盖需指向性明确，会话内有效。

（判定卡与建设性冲突规格见 ROADMAP §1.3、§4.M2.2）

## 五、全局红线

**数据与安全**：传感默认关；出网 100% 过安全网关（黑词本机保留+占位混淆）；主动只建议不执行；物理动作三级审批+读回验证；GPL/AGPL 只学思路。

**人格宪法三红线**：不做心理诊断 / 不表演情绪 / 不主动解析。

**话术四原则**：好奇不质询、先服务后学习、确认带选项、永不翻旧账。

**依赖设计边界**：置信度自然语言化+可追问依据+偏离惯例确认（防认知卸载）。

（完整版见 ROADMAP §1.5）

## 七、实施切片（当前冲刺）

**MVP 四条硬基线（阻塞发布）**：M0.2 出网安全网关 ｜ M1 记忆数据轨（五要素 schema+双轨架构位+冲突协议）｜ M2 姿态路由四态骨架（管家/朋友/陪伴/医护）｜ M0 宏观四态状态机（DORMANT 冻结=安全行为）。

**两周冲刺**：出网安全网关（半天）→ 记忆数据轨骨架（一周）→ 情感两变量+星云映射+宏观四态（三天）。呈现轨 180 天滤镜合法延后（MVP 记忆库存不满 180 天天然不触发）。验收以 specs/EVAL.md 四场景为准；M2 真路由上线前须过影子日志 ≥1 周+灰度 5-10 人。

**冲刺前置任务（v4.1.1）**：二批九场景中直接决定 M1/M2 实现决策的 4 个（姿态路由正确性 / 闭嘴期被动响应 / 任务态默认方向 / 听错复述确认）**必须在 M0.2 动工前把断言写死**——实现完再补断言必返工。

**MVP 精神**：先让一个人愿意每天打开它，再让它变成全能型陪护人。设计已经足够完善，实施以最小可感闭环优先，勿因规格完备而拉长周期。
